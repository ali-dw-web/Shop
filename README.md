# 🛒 Modern Shop Website

> A full-featured e-commerce platform built with **Next.js**, **React**, and **Tailwind CSS**.  
> Browse products, manage orders, and enjoy a seamless shopping experience across all devices.

---

## ✨ Key Features

- 🛍 Browse, search, and filter products easily    
- 📦 Checkout system with order preview  
- 🎨 Fully responsive and modern UI design
- wishList for the next visit

## 🔍 Item Details

Each product or room on the platform is interactive:

- Click on any item to view **detailed information** including description, features, and pricing.  
- Easily check availability, specifications, reviewa , and images without leaving the page.  
- Provides a smooth and intuitive experience for users to explore all options before making a purchase or reservation.

## 💬 Reviews / Feedback

- Users can leave **reviews** for any product or room.  
- Each review can include **ratings, comments, and feedback** .  
- Reviews are displayed in real-time

## 🛒 Shopping Cart

- The **Shopping Cart** displays all selected products or rooms before checkout.   
- All cart data is **managed with Zustand**,
- Changes are instantly reflected across the site for a smooth shopping experience.  
- Provides a **clear overview** of total items, prices, and order summary before proceeding to payment.
- <img width="1366" height="645" alt="Screenshot (43)" src="https://github.com/user-attachments/assets/57e165f3-d79c-4702-af20-7f9b94feafc2" />

## ⭐ Wishlist (Favorites)

- Users can **add products or rooms to their Wishlist** to save items for later.  
- All Wishlist data is **stored in Local Storage**,  
- Provides a **quick way to access favorite items** without navigating through the entire section  
- Supports **adding, removing, and viewing items** easily, enhancing the shopping experience.
